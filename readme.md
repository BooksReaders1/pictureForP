# Pixiv 图片查看器

一个简洁的 Pixiv 图片浏览工具，支持多张图片并发加载、批量下载等功能。

## ✨ 特性

### 核心功能
- **图片浏览**：自动发现并加载 Pixiv 作品的所有图片
- **并发加载**：使用并发请求加速图片发现和加载
- **批量下载**：支持将所有图片打包为 ZIP 下载
- **响应式设计**：完美适配桌面端和移动端

## 🚀 快速开始

### 使用方法
1. 直接在浏览器中打开 `index.html` 文件
2. 在 URL 中添加 `?pid=作品ID` 参数即可浏览对应作品

### 示例
```
https://your-domain.com/index.html?pid=12345678
```
